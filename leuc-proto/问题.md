# 问题与结论

## 账号与登录

| 问题 | 结论 |
|------|------|
| 手机号、邮箱在本系统是否独立？非独立能否编辑？编辑会被覆盖吗？ | **独立**（本系统自管，不随外部覆盖） |
| 飞书、北森是否默认可登录，无需申请？ | **可以**，直接登录 |
| 飞书 / 企微登录后，是否按手机、邮箱自动绑定？ | 飞书、北森：**自动绑定**；本系统绑定：**独立、可换** |

## 用户名规则

| 类型 | 规则 |
|------|------|
| 内部 | 默认用集团 ITCode |
| 外部 | 加 `lec_` 前缀区分（可修复） |

**用户名调研：**

- 约 85% 为手机号；另有 ID 等
- 倾向方案：优先手机号；或用户名用拼音全拼

## 离职与权限关闭

| 问题 / 需求 | 结论 / 说明 |
|-------------|-------------|
| 离职如何处理？ | 拉取通讯录判断人员状态；离职直接关闭所有系统账号，**无需审核** |
| 权限申请是选择还是输入？ | **输入** |
| 拒绝后如何处理？ | 直接到系统管理员进行关闭 |
| 「账号、权限关闭」入口 | 不需要单独入口；在账号权限审批里可关闭即可 |
