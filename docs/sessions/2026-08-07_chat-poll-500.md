# 会话：chat/poll 500

- 日期：2026-08-07
- 范围：`leuc-proto` SQLite 并发初始化 / Docker journal

## 原因

1. `get_db()` 每次请求调用 `ensure_db()` → `init_db()`/`executescript`，前端 poll 高频并发打爆绑定卷 SQLite
2. Windows Docker 绑定卷上 WAL 不稳定，出现 `disk I/O error` / `no such table: users`

## 修复

- `ensure_db` 加锁且进程内默认只执行一次
- `get_db` 请求路径不再反复初始化
- Docker 默认 `LEUC_SQLITE_JOURNAL=DELETE`
- `connect` 增加 `busy_timeout` / `check_same_thread=False`

## 验证

登录后 12 路并发 `/api/chat/poll` 均为 200。
