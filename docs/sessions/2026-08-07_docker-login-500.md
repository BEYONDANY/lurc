# 会话：Docker 登录 500

- 日期：2026-08-07
- 范围：`leuc-proto/db.py` SQLite 在 Docker 绑定卷上的 I/O 错误

## 原因

Windows Docker 绑定卷上 SQLite WAL 残留（只删 `.db` 留下 `-wal`/`-shm`）导致 `disk I/O error`，登录等接口 500。

## 修复

1. 清理损坏库并重建种子
2. `init_db(force=True)` 同步删除 `-wal`/`-shm`
3. `connect()`：WAL 失败时回退 `DELETE` journal

## 验证

`POST /api/login`（admin/123456）返回 200。
