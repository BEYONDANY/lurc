# 修复角色配置保存后被软补种冲掉

## 背景
「角色与权限 · 按角色」点保存后勾选看起来没生效。

## 原因
`ensure_roles_seeded` 每次请求都对默认菜单/按钮 `INSERT OR IGNORE`，管理员去掉的默认项会被重新插入；列表接口在空配置时还会回退展示默认值。

## 改动
- `db.py`：缺省菜单/按钮仅在该角色库内为空时补种；新增 `schema_patches` 一次性补丁（oa_forms / 部门按钮 / 改密按钮等）
- `app.py`：角色列表以库内配置为准，不再空配置回退默认
- `static/index.html`：保存请求对 role 做 `encodeURIComponent`

## 验证
- 语法 AST 通过
- 手测：去掉某角色一个默认按钮 → 保存 → 刷新仍保持未勾选；新登录该角色侧栏/按钮与配置一致
