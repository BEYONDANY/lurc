# 会话：LEUC 同步/任务/外部人员/审批流优化

## 需求覆盖
1. 自动同步（默认 6h）+ mobilePhone + 新用户自动生成登录名/密码并发信落库
2. 任务管理（可改频次、启停、立即执行）
3. 发信记录列表（不真实发送）
4. 内置「外部人员」部门；新建仅外部；菜单仅个人中心+密码管理
5. 延期审批详情展示权限（突出敏感）
6. 审批末节点申请人确认后关闭
7. 知会系统管理员直接领导（阅读确认，不阻塞）
8. 可驳回到指定节点
9. 同系统管理员合并申请；含敏感走敏感链
10. 本系统 LEUC 加入可申请权限目录

## 关键文件
- `leuc-proto/leuc_ops.py` / `leuc_approval_ext.py`
- `leuc-proto/db.py` / `app.py` / `static/index.html`
