# 审批流程：完整时间线 / 提交按钮 / 撤销

## 需求
1. 流程时间线保留完整链路（含驳回、再提交）
2. 驳回至起点时主按钮为「提交」而非「通过」
3. 未结束申请可撤销

## 实现
- 新增 `application_flow_events`；发起/通过/驳回/重提/撤销写事件
- `build_application_flow` 按事件拼时间线，并展示当前待办与预测节点
- 列表/详情：`can_resubmit` 时按钮「提交」；`POST /api/applications/<id>/cancel` 撤销

## 验证
- 延期申请 → 驳回至申请人：时间线含发起、驳回、申请人修改重提；按钮可提交
- 重提后时间线含「再次提交」与当前审批节点
- 撤销后状态 `cancelled`，时间线含撤销事件
