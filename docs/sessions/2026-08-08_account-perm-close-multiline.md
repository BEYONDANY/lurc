# 会话：账号权限关闭改为多行表单

## 目标

「账号、权限关闭」与「账号、权限申请」表单操作一致：选系统→账号→关闭类型（账号/权限）；权限时可树选权限并勾选是否关闭敏感；支持多行；审批详情按多行展示。

## 改动

- `static/index.html`：关闭面板改为行表；`account_perm_close` 批量提交
- `app.py`：`account_perm_close` 落库 `items`；审批按行执行关登录/权限/敏感
- `leuc_approval_ext.py`：关闭明细表列与申请对齐（含关闭类型/权限/敏感）
