1. 背景与目标


为企业级「自研 CAS 统一认证中心」（方案 A）在 SaaS 场景下过重、且与 Board「不要 CAS/SAML、要多租户、锁 Logto」结论冲突。方案 O 采用：


**Logto 提供 OIDC/OAuth2.1 与会话；自研租户·成员·应用治理·权限只读目录；企业连接器可插拔。**


2. 范围


2.1 一期做


  • 邮箱验证码 / 密码登录（凭证在 Logto）
  • Tenant / Membership / Invite
  • 第一方与租户应用 OIDC（Auth Code + PKCE）
  • 应用注册、回调白名单、secret 一次展示
  • 租户 RBAC + 跨应用权限只读聚合
  • 审计、登出、管理员踢人
  • C 端门户 + 管理后端（HTML demo + 现有 apps/web 切片）

    • 2.2 一期不做


  • CAS / SAML（含 Bridge）
  • 短信通道、Passkey（二期）
  • 业务菜单/数据权限实时鉴权
  • 飞书组织全量同步（作企业版连接器）

    • 3. 角色与端


    端用户能力
    登录门户未登录访客OTP / 密码 / 可选 Social
    C 端（成员门户）租户成员工作台、我的应用、个人安全、工单
    管理后端Owner/Admin成员、应用审核、权限目录、策略、审计

    4. 架构摘要


    见 `架构图/01-总体架构图.html`。硬边界：


  • 凭证只存 IdP
  • 业务本地会话与 IdP Session 分离
  • 权限聚合只展示
  • 无 CAS ticket

    6. 风险


    风险缓解

  • 本优化包目录完整（对齐方案 A 截图三文件夹）

  • 开工包契约/DDL/Backlog/测试可指导继续硬化
