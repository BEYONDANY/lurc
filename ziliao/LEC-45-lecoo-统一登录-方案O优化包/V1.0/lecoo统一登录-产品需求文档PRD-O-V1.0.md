# lecoo 统一登录 · 产品需求文档 PRD（方案 O）V1.0

> 版本注记：O-V1.5 增量 — 手机版 + 人脸/指纹/多因子认证交互

## 1. 产品定位

为 lecoo SaaS 提供**多租户统一登录与应用治理**：成员用一套身份进入租户与已授权应用；管理员管理成员、应用与权限目录。支持 **桌面端与手机端**，并提供 **MFA / 人脸 / 指纹** 等安全认证能力。

## 2. 用户故事（一期）

1. 作为访客，我可以用工作邮箱验证码登录。  
2. 作为 Owner，我可以创建租户并邀请成员。  
3. 作为成员，我可以在 C 端看到已授权应用并一键进入。  
4. 作为 Admin，我可以审核应用、重置密钥、查看审计。  
5. 作为 Admin，我可以浏览跨应用权限目录（只读）。  
6. 作为 Admin，我可以踢出异常会话。  
7. 作为手机端用户，我可以用面容 / 指纹快速解锁本机会话。  
8. 作为高风险操作执行者，我需要完成 MFA 或生物识别 Step-up 后才能继续。  
9. 作为 Admin，我可以配置租户级 MFA / 生物识别强制策略。

## 3. 页面清单（对齐原型）

### 登录门户（桌面）
- 邮箱验证码 Tab、密码 Tab、企业 SSO、错误态
- MFA 第二因子挑战（TOTP / 短信 / 邮箱 / 备用码 / 生物识别）

### 手机版（C 端）
- 启动登录页、生物识别解锁、密码登录、MFA 挑战
- 工作台应用宫格、安全与生物识别设置

### 安全认证交互原型
- MFA 多因子挑战流
- 人脸识别登录流、指纹解锁流
- 生物识别注册 / 吊销
- 敏感操作 Step-up
- 管理端 MFA / 生物识别策略配置

### C 端（桌面）
- 工作台、个人中心、我的应用、创建应用、应用详情、工单中心

### 管理后端
- 仪表盘、用户/成员、组织/租户信息、应用、授权、流程/工单、策略（含 MFA/生物识别）、审计

## 4. 非功能

- 可用性：登录核心路径 P1；手机端核心路径 P1  
- 安全：MFA、生物识别（WebAuthn/平台生物）、防爆破、审计；见开工包 SEC-*  
- 合规：一期不对齐等保三级全量；生物特征模板不出设备，仅存 credential 引用  
- 体验：手机框原型 ≤430px 可演示完整闭环  

## 5. 成功指标

- 受邀成员 24h 内激活率  
- 登录成功率 ≥ 99%（排除用户输错）  
- MFA 挑战成功率 ≥ 98%（排除用户取消）  
- secret 泄露工单响应 < 15 min（吊销）
