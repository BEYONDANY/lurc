## 角色与权限（可配置）

- **角色清单**：可新增自定义角色、改显示名；内置角色不可删（可改名）；删除自定义角色时占用人员改回普通员工
- **菜单**：控制侧栏可见模块
- **按钮**：挂在菜单下，控制页面操作显隐（如添加人员、代人申请、添加系统等）
- 超管进入「系统设置 → 角色与权限」以**权限树**勾选保存（分组 → 菜单 → 按钮；蓝标菜单 / 橙标按钮；勾菜单自动勾下属按钮）；可按姓名检索给人分配角色
- 按钮目录示例：`org_add` / `proxy_apply` / `direct_bind` / `set_account_expire` / `sys_add` / `sys_perm_edit` / `config_roles`

## 我的组织 · 账号有效期

- **可见条件**：角色按钮 `set_account_expire`（或人员开通字段兼容）
- **能力**：勾选人员或行内入口 → 指定到期日 / **永不过期**（存空）
- 个人「安全管理」中有效期仍为只读，延期走自助申请

## 业务系统管理

- **系统管理员**：仅看**自己负责**的系统；可设启停、敏感复选框、凭证、权限目录（同步/导入）、账号池
- **超级管理员**：看全部；可添加系统并指定**多名**系统管理员
- **是否有敏感权限**：系统级复选框，**与权限目录无关**
- **权限目录**：系统管理员维护 / 子系统同步 / 手动导入（人员与账号池在「系统账号管理」同步导入）

## 敏感审批链（仅超管）

- 配置开通/关闭敏感时的审批链（直属 → 一级 → 财务）
- 申请敏感：系统开启「是否有敏感权限」后，在账号申请中勾选「同时申请敏感权限」

## 自助申请（仅本人）

| 类型 | 说明 | 审批 |
|------|------|------|
| 账号延期 | 默认 +90 天 | 直属 |
| 账号、权限申请 | 先选系统 → 再选已绑定账号（单选）或不选/无账号则勾新建；树状权限；敏感单独列 | 新建→系统管理员确认；普通权限→直属；敏感→长链 |
