# 会话：申请登录 → 账号绑定

日期：2026-08-04

## 变更摘要

将「申请登录 / 批量开通 / 批量授权」统一为 **账号绑定**：

- 一个 LEUC 账号可绑定多个系统账号（多选）
- 超管 / 人事专员：`/api/bind/direct` 直接绑定
- 组织负责人 / 员工：`/api/bind/apply` 申请绑定，系统负责人确认
- 准入文案：申请登录 → 需账号绑定；待办类型兼容「账号绑定 / 账号授权」

## 主要文件

- `leuc-proto/app.py`：bind API、待办兼容
- `leuc-proto/static/index.html`：直接绑定 / 申请绑定 UI
- `leuc-proto/README.md`、`V2.0/用户中心功能模块整理-O-V2.1.md`
