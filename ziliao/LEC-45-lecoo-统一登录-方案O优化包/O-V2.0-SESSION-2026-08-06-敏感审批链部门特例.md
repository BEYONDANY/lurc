# 会话记录 · 敏感审批链部门特例（2026-08-06）

## 目标

`flow=sensitive`：直属/一级默认动态解析，可按「申请人所属部门」指定审批人（不继承父子）；财务仍固定人；选人复用组织筛选。

## 规则（已确认）

- 动态示例：徐好好 ∈ BTIT → 直属马宁；一级产品营销 → 吴锦志
