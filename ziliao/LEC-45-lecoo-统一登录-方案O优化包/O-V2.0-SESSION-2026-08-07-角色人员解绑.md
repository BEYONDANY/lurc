# 会话：角色人员查看与解绑

日期：2026-08-07

## 目标

角色与权限页：查看各角色下有哪些人；可解除人员与角色绑定。

## 变更

1. `GET /api/admin/roles/<role>/members`：列出本角色人员（可搜，最多 200）
2. `DELETE /api/admin/users/<id>/role`：解绑 → 改回普通员工
3. 保护：系统超管 `admin` 不可解绑；至少保留一名 `super_admin`
4. 前端：选中角色后展示「本角色人员」表 +「解除绑定」；分配后刷新列表
5. 查看权限放宽：`role_assign` 也可打开角色页（菜单树只读）

## 手测

1. admin → 角色与权限 → 点「部门负责人」见人员列表
2. 解除绑定 → 变为普通员工；再分配可恢复
3. 对 admin 解绑应失败
