# O-V2.0 更新记录 · 用户中心身份治理与安全审计

- 更新日期：2026-07-31
- 原型文件：`V1.0/用户中心交互原型-O-V2.0.html`
- 版本定位：在 O-V1.5 登录、移动端和安全认证能力之上，补齐用户中心身份治理与账号审计闭环。

## 本次更新

1. 明确两大模块：统一登录与账号安全、身份治理与安全审计。
2. 新增账号关联工作台，支持 ITcode、OA 编号、手机号、邮箱、姓名等分层匹配及人工捏对。
3. 新增系统账号台账，展示统一身份、组织、负责人、准入范围、认证有效期和执行方式。
4. 新增账号生命周期任务，统一承载 API 自动执行与线下执行回执。
5. 新增成本查看权限责任链复核；当前治理范围仅包含成本权限。
6. 新增季度审计核查，覆盖账号差异、离职账号清零、责任确认、整改和汇报。
7. 组织架构支持飞书或北森同步；部门负责人、一级领导、财务负责人支持推导或人工指定。
8. SSO 配置增加北森入口，保留飞书、企业微信和通用 OIDC。
9. 取消独立的“安全认证交互”入口：MFA、人脸、指纹、凭证注册和 Step-up 归入登录与员工入口；认证策略归入管理后台。
10. 新增季度核查独立流程页：按用户汇总全部系统账号和成本敏感权限，支持本人确认、负责人复核、成本权限加签、系统整改与审计归档流转。
11. 员工入口新增部门账号管理：负责人或部门上级可在授权组织范围内设置人员可登录系统、账号有效期，发起新建、延期、关闭及批量操作。
12. 原型可见文案统一使用“待办”；员工入口“工单中心”更名为“我的待办”。

## 2026-08-04 审批规则（leuc-proto）

1. 申请账号 / 密码延期 / 普通权限 → **直属审批**。
2. 敏感权限、外部人员 → **直属 → 一级 → 财务**（申请人=审批人时跳过）；敏感通过后自动开通。
3. 注销：北森单据通过后 **系统直接关闭**关联账号，不经系统负责人确认待办。
4. 新开账号：同步可编辑用户名后直接创建；手动添加分内部/外部并确认用户名。
5. 系统管理：`forbid_external`（北森/飞书默认开启）；外部人员不可登录禁外系统。
6. 文档：`V2.0/用户中心功能模块整理-O-V2.1.md`。

## 2026-08-06 安全管理（leuc-proto）

1. 个人「安全管理」支持：密码修改、手机/邮箱添加改绑、账号有效期（只读）、人脸/指纹录入删除、SSO 查看绑定与解绑。
2. 「密码延期」改为「账号延期」：直属审批通过后延长 `account_expire`（默认 +30 天）。
3. API：`/api/security/password|contact/*|bio|sso`；改绑演示码 `888888`。
4. 用户表新增 `account_expire`、`face_enrolled*`、`fingerprint_enrolled*`。
