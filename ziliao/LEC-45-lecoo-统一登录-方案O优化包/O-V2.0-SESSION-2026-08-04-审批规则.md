# 会话：审批规则对齐（直属 / 一级+财务 / 北森直关）

> 日期：2026-08-04 · 原型 `leuc-proto`

## 结论

按业务规则落地自助申请与注销：

| 类型 | 审批 |
|------|------|
| 申请账号 / 密码延期 / 普通权限 | 直属 |
| 敏感权限 / 外部人员 | 一级领导 → 财务 |
| 注销 | 北森单据 → 系统直接关账号（无负责人待办） |
